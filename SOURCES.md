# OpportunityBridge Source Verification Notes

**Verified snapshot:** September 4, 2026  
**Programs in this build:** 80

OpportunityBridge includes a program only when an official current source indicates that the program still exists. A listing may be currently open, opening for a named future cycle, accepting interest/nomination forms, recurring with its next application window pending, or operating as an active opportunity directory. Programs that could not be verified as active on an official source were not added.

## Verification standard

- Official organizer, government, university/consortium, or official application pages are used instead of third-party scholarship lists.
- If an exact next-cycle deadline has not been published, the site says so rather than extrapolating a date.
- “Upcoming” and “next cycle pending” mean the program itself is confirmed active, not that applications are currently open.
- Deadlines and eligibility can change after this snapshot. The linked official source always controls.
